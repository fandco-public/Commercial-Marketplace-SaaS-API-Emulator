# Support

## How to file issues and get help

**The upstream repository is archived and accepts neither issues nor pull requests.** Microsoft
archived [microsoft/Commercial-Marketplace-SaaS-API-Emulator](https://github.com/microsoft/Commercial-Marketplace-SaaS-API-Emulator)
in September 2026 without naming a successor.

Raise anything about **this fork** through this repository's own issues. The fork is maintained by
Freytag & Company, LLC; security concerns go to [team@freytag.us](mailto:team@freytag.us) rather than to a public
issue — see [SECURITY.md](./SECURITY.md).

## Microsoft Support Policy

Microsoft's original support statement for this project limited support to GitHub issues on the
upstream repository, and that repository is now archived. There is therefore no active Microsoft
support channel for the emulator. (Microsoft's original text left the placeholder
"**PROJECT or PRODUCT**" unfilled.)

For the marketplace APIs the emulator imitates - as opposed to the emulator itself - the
supported route is [Partner Center support](https://learn.microsoft.com/partner-center/report-problems-with-partner-center).
For security matters see [SECURITY.md](./SECURITY.md), which separates this fork's modifications
from the inherited Microsoft code.
