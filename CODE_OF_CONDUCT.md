# Code of Conduct

This fork, maintained by Freytag & Company, LLC, adopts the
[Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/) by
reference. Its text and the accompanying
[FAQ](https://opensource.microsoft.com/codeofconduct/faq/) apply to participation in this
repository.

Adopting the document does not make Microsoft responsible for conduct here. Microsoft archived
the upstream repository in September 2026 and has no role in this fork.

**Questions or concerns about conduct in this repository go to
[team@freytag.us](mailto:team@freytag.us)**, not to Microsoft.
